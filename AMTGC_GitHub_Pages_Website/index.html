Adaptive Multi-Junction Traffic Controller

A coordinated traffic-control system for two 4-way junctions with adaptive timing, green-wave coordination, pedestrian arbitration, and emergency override.

View GitHub Project Explore Project

PROJECT OVERVIEW

AMTGC at a glance

Objective

Design and verify an adaptive traffic controller that coordinates two traffic junctions while responding to traffic density, pedestrian requests and emergency conditions.

Design

The architecture uses two junction controllers and a shared pedestrian arbiter with a green-wave trigger between junctions.

Verification

The design is simulated using Verilog testbenches and ModelSim, with waveforms and verification evidence included in the project.

CORE FEATURES

System capabilities

01

Two 4-Way Junctions

North-South and East-West traffic sequencing at Junction A and Junction B.

02

Green-Wave Coordination

Junction B is coordinated with Junction A using a configurable wave delay.

03

Adaptive Timing

Green duration can respond to the configured traffic-density input within defined limits.

04

Pedestrian Arbiter

A shared arbitration mechanism receives pedestrian requests and grants service fairly.

05

Emergency Override

An emergency input forces both junctions toward a safe all-red condition.

06

Simulation & Verification

RTL, testbench, simulation and waveform artifacts are organized in the submission package.
