# AMTGC GitHub Pages Website

This folder contains a standalone GitHub Pages website for the AMTGC internship submission.

## Before publishing
Open `index.html` and replace both occurrences of:

`https://github.com/YOUR-USERNAME/YOUR-REPOSITORY`

with your actual public GitHub repository URL.

## Publish
Upload `index.html` and `style.css` to a GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → / (root) → Save.

The resulting URL will normally be:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
